# Sponsorship

The Visio-Azure stencils are **free and open** under GPL-3.0: the full collection, both unit systems, everything you need to use the icons in Visio. There is nothing to buy.

If they save you time and you appreciate the work, sponsoring helps keep the set maintained and regenerated as Microsoft refreshes its Azure icons. Any amount, one-off or monthly, is genuinely appreciated.

[Sponsor on GitHub →](https://github.com/sponsors/xeeva){: .btn }

## Premium (coming soon)

A separate **Premium** set is in the works, bundling the parts that take ongoing effort to produce and maintain:

- Per-icon **SVG** files and **PNG** renders, ready for slides, docs, and the web
- **Styled** Visio stencil variants for design-led diagrams
- Early access to new releases

The details are still being worked out, so there is nothing to sign up for yet. If you'd like it when it lands, [sponsoring](https://github.com/sponsors/xeeva) is the best way to register your interest.
