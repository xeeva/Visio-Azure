# Azure Visio Stencil Pack

**Visio-Azure** is a free, complete **Azure Visio stencil** pack: **1,764 Microsoft Azure
service icons** packaged as ready-to-use Visio stencils (`.vssx`), with working shape
search, nine connection points per icon, resource shape data, and both Metric and US-unit
builds. It is a drop-in **alternative to Microsoft's Azure Visio stencils**, which
Microsoft no longer ships as stencil files.

## What is an Azure Visio stencil?

A Visio stencil is a `.vssx` file containing reusable master shapes that appear in Visio's
**Shapes** panel. An **Azure Visio stencil** holds the Microsoft Azure service icons as
proper Visio masters, so you can drag a service onto the canvas, glue connectors to fixed
anchor points, search by name, and attach metadata, rather than pasting flat images.

Visio-Azure turns the entire current Azure icon set into one such stencil pack: every icon
is a clean vector, normalised to the same drop size, with the Visio features that make a
diagram maintainable.

## Why Microsoft no longer ships Azure Visio stencils

Microsoft publishes its Azure architecture icons as **SVG and PNG downloads**, not as
Visio stencils. Dropping those raw images into Visio gives you artwork with none of the
stencil behaviour: no connection points, captions land over the icon, sizes vary wildly,
there is no shape data, and shape search finds nothing.

Visio-Azure exists to close that gap, the **alternative to Microsoft's Azure Visio
stencils**: it converts the official Azure architecture icons into a fully-equipped Visio
stencil pack so you get search, anchors, sizing, and shape data out of the box.

## Metric or US units?

The pack ships in two identical builds that differ only in their internal Visio
measurement units: **Metric** (`_m`) for centimetre/millimetre drawings and **US** (`_u`)
for inch/feet drawings. Match the build to your drawing or icons drop at the wrong size and
search can miss them. See [Metric vs US units](units) for the full explanation.

## Frequently asked questions

**Is it free?** Yes, the full **Azure Visio stencil** pack is free and open under GPL-3.0;
the icon artwork remains copyright Microsoft. See the [FAQ](faq) and [Licence](faq).

**Which Visio versions work?** Visio for Microsoft 365 (Windows and Mac) and Visio
2019/2021/2024 desktop. Visio for the Web cannot load custom `.vssx` files.

**Why isn't search finding the icons?** Either a unit mismatch or Visio's shape search is
off, see [Enabling search](enabling-search).
