The problem

Stencils are scattered and inconsistent

The Azure stencils you can find are a patchwork: hundreds of products spread across many separate stencils from different providers, often mixing raster PNG icons with vectors, dropped at wildly different sizes, with no connection points or shape data, and many already out of date. Pulling a clean diagram together means hunting across sets that never quite match.

The solution

One unified, standardised set

Visio-Azure is one unified Azure Visio stencil pack: 1,764 masters across 17 groups, every one a clean vector normalised to the same size, with connection points, shape data, and working search, generated programmatically and verified against a per-master contract on every build.

Straight from the official stencils

This is what you get dropping icons from the various official stencils onto one page, not Visio-Azure. The same set arrives at wildly different sizes and aspect ratios: Azure Sphere and Azure Workbooks dwarf their neighbours, Azure DevOps lands small and cramped, and Azure AD Domain Services (its name now out of date, correctly Entra ID Domain Services) is tall and narrow where the rest are roughly square. Pulled together, it reads as a collage rather than a diagram.
